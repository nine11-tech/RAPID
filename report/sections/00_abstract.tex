\begin{abstract}
\noindent
\textbf{Real-Time Cybersecurity Threat Detection using Lambda Architecture}

\vspace{0.7em}

\noindent
This report presents the design and implementation of a real-time cybersecurity 
threat detection system based on the \textbf{Lambda Architecture}. In modern 
networked environments, cyber threats are becoming increasingly sophisticated, 
frequent, and data-intensive. Traditional batch-only security analysis is no 
longer sufficient, since it mainly provides delayed insights after incidents 
have already occurred. To address this limitation, our system combines 
\textbf{historical batch processing} with \textbf{low-latency stream processing}, 
allowing both deep forensic analysis and near-real-time threat detection.

\vspace{0.8em}

\noindent
The proposed solution relies on a complete Big Data pipeline composed of several 
industry-proven technologies:

\begin{itemize}
    \item \textbf{Apache Kafka} for continuous log ingestion and event streaming;
    \item \textbf{Apache Spark} for batch analytics and real-time stream processing;
    \item \textbf{HDFS} for distributed storage of historical cybersecurity logs;
    \item \textbf{HBase} for serving precomputed batch views;
    \item \textbf{Apache Cassandra} for storing active and recent threats;
    \item \textbf{Flask REST API} and an \textbf{HTML/JS dashboard} for unified visualization.
\end{itemize}

\vspace{0.5em}

\noindent
The system is able to detect several categories of network threats, including 
\textbf{brute-force attacks}, \textbf{SQL injection attempts}, 
\textbf{port scanning activities}, and \textbf{abnormal data transfer patterns}. 
The real-time layer achieves an end-to-end alert latency of less than 
\textbf{five seconds}, making the platform suitable for fast security monitoring 
and incident response. In addition, a bonus \textbf{Random Forest} classifier was 
trained using MLlib on labeled log data and achieved \textbf{92\% classification 
accuracy}. This machine learning experiment also revealed important 
\textbf{class-imbalance issues} through DuckDB-based exploratory analysis.

\vspace{0.8em}

\noindent
Overall, this project demonstrates how a well-designed Big Data architecture can 
serve as the foundation of a cybersecurity monitoring platform. By combining 
scalability, fault tolerance, historical intelligence, and real-time responsiveness, 
the proposed system provides a practical approach for detecting and visualizing 
cybersecurity threats in large-scale environments.

\vspace{0.8em}

\noindent
\textbf{Keywords:} Cybersecurity, Big Data, Lambda Architecture, Apache Kafka, 
Apache Spark, HDFS, HBase, Cassandra, Real-Time Detection, Threat Monitoring.
\end{abstract}
