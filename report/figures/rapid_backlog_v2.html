Setup
Guide Setup Docker Swarm + Tailscale
A faire une seule fois avant Sprint 2 · Ordre strict a respecter
Etape 1 — Tailscale VPN (tous les membres, 5 minutes chacun)
Tailscale cree un reseau prive entre vos machines. Chaque machine obtient une IP fixe 100.x.x.x accessible depuis partout sans configuration reseau complexe.

1. Installer Tailscale : https://tailscale.com/download
2. Se connecter avec un compte Google ou GitHub
3. Anass cree un compte d'equipe et partage le lien d'invitation
4. Chaque membre recupere son IP : tailscale ip -4
5. Partager les IPs dans le groupe WhatsApp
Etape 2 — Initialiser Docker Swarm (Anass uniquement)
docker swarm init --advertise-addr $(tailscale ip -4)

Copier le token affiche qui ressemble a :
docker swarm join --token SWMTKN-1-xxx 100.64.0.1:2377

Envoyer ce token exact aux trois autres membres.
Etape 3 — Rejoindre le Swarm (Chawi, Hamza, Khalid)
Chaque membre colle et execute le token recu :
docker swarm join --token SWMTKN-1-xxx 100.64.0.1:2377

Verifier sur la machine Anass que les 4 noeuds sont visibles :
docker node ls

Resultat attendu: 1 manager (Anass) + 3 workers actifs.
Etape 4 — Reseau overlay Swarm (Anass)
Creer un reseau overlay pour que tous les conteneurs se voient entre machines :
docker network create --driver overlay --attachable rapid-overlay

Chaque docker-compose.yml utilisera network: rapid-overlay pour ses services.
Etape 5 — Lancement par membre
Anass lance ses services :
docker-compose up -d namenode datanode zookeeper kafka

Chawi lance ses services :
docker-compose up -d cassandra hbase

Hamza lance ses services :
docker-compose up -d spark-master spark-worker

Khalid lance son service :
docker-compose up -d spark-streaming
Etape 6 — Fichier .env.local par membre (git-ignore)
Chaque membre cree un fichier .env.local avec les IPs Tailscale reelles :

ANASS_IP=100.64.0.1  # HDFS, Kafka, Zookeeper, API
CHAWI_IP=100.64.0.2  # Cassandra, HBase, Dashboard
HAMZA_IP=100.64.0.3  # Spark Master
KHALID_IP=100.64.0.4 # Spark Streaming

Ces variables sont utilisees dans tous les scripts Spark et Python.
Etape 7 — Verification de la connectivite
Hamza teste HDFS d'Anass :
curl http://100.64.0.1:9870 doit retourner la page HDFS UI

Khalid teste Kafka d'Anass :
nc -zv 100.64.0.1 9092 doit repondre connection succeeded

Chawi teste sa Cassandra locale :
cqlsh 127.0.0.1 doit ouvrir le shell Cassandra

Hamza teste Spark UI local :
curl http://localhost:8080 doit retourner Spark Master UI
